# 单篇 AI 问答错误返回原始 RAG 切块

## 现象

- 触发页面：进入「AI 问答」，选择「单篇文献」，选中文献后提问。
- 实际结果：回答区直接显示相似度最高的英文切块，并将其标成助手回答；标题旁还重复显示较长的范围说明。
- 期望结果：模型读取当前论文的已解析正文，按提问语言生成有依据的回答；标题只保留「AI 问答」。

## 原因

- 独立问答页始终以默认 `use_document_context=false` 调用 `POST /rag/query`。
- 默认知识库检索路径的确定性降级会返回最高分原始切块，前端又统一使用「助手 · 引用 RAG 切块」展示，导致检索证据被误认作综合回答。
- 范围信息已在左侧选择器完整呈现，标题栏的 `scope-summary` 属于重复信息。

## 修复

- 单篇文献范围调用 `POST /rag/query` 时发送 `use_document_context=true`，复用接口契约中已有的当前论文正文问答能力。
- 单篇回答显示为「助手 · 当前论文」，不再展示不适用的向量相似度提示；引用继续以结构化来源按钮回链原文。
- 当阅读器记住的是同一篇文献但段落尚未载入时，点击引用会重新加载正文后再定位，避免进入空阅读页。
- 删除标题栏的范围摘要，并把输入区提示改为可点击的原文引用说明。
- 项目问答和全库 RAG 仍保留原有向量检索路径。

## 验证

- Web 回归测试检查范围摘要已移除、单篇请求启用正文上下文、回答标签和引用提示正确。
- API 既有测试继续覆盖当前论文正文问答、同语言回答提示、机器引用尾注清理和来源定位。
- 聚焦回归：`5 passed`。
- 浏览器实测：中文综合回答正常生成，不显示旧范围摘要或向量相似度横条；点击 Conclusion 引用可落到双语阅读第 8 段，控制台无 warning/error。
- 完整 gate：`EMBEDDING_MODEL=local-hash VECTOR_DB_BACKEND=local-json VECTOR_DB_PATH=<临时文件> .venv/bin/python -m pytest -q` → `1390 passed, 5 warnings in 237.88s`。
