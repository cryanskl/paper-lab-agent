# 在线检索轮询函数与浏览器全局名称冲突

## 现象

- 触发页面：`/ui/`
- 实际结果：`app.js` 加载后导航与工作区保持空白，检索页面没有显示。
- 期望结果：工作台正常启动，并显示“检索本地库”和“在线同步并检索”两个入口。

## 原因

- 在线同步轮询新增了顶层函数 `wait()`。
- 目标浏览器环境已有同名且不可重定义的全局属性；经典脚本声明顶层函数时发生宿主环境冲突，脚本在注册 `DOMContentLoaded` 启动逻辑前中止。
- `node --check` 只能检查语法，无法覆盖浏览器宿主环境的全局属性冲突。

## 修复

- 将轮询 helper 改为项目专用名称 `waitForOnlineSearchPoll()`。
- 保留浏览器运行态验证，检查导航、双检索按钮、本地结果和页面加载状态。

## 验证

- RED 证据：浏览器 DOM snapshot 只有空导航与系统状态占位，`boot`、`state`、`$` 均未初始化。
- GREEN 证据：浏览器复测显示完整导航、系统状态、178 条本地结果、“检索本地库”和“在线同步并检索”按钮；本地检索完成后无加载残留。
- 完整 gate：`bash scripts/release_check.sh` -> `1296 passed`。
